## What it does

`main.py` writes a single one-line warning label for a time machine — 120 characters at most — to `/output/entry.txt`:

> WARNING: If you meet yourself during operation, do not wave. He is already running late, and it is entirely your fault.

The joke turns a real time-travel hazard, meeting your own duplicate self, into a deadpan safety notice, and saves the blame for the last few words.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
